# Employee Context Router

- Identity and goals: load the byte-preserved instance files included in the launch packet.
- Project instructions: discover the selected project's `AGENTS.md` or harness-native equivalent when project work begins.
- Tools and skills: query the harness registry at point of use; do not snapshot or enumerate installed capabilities in bootstrap context.
- Memory: load only relevant instance-owned memory for the active request.
- Current work: on continuation, consume exactly one bounded Cortext handoff through its lease.
- Precedence: explicit audited owner safety decision, current framework core/router, instance-owned identity/goals/user rules, selected project instructions, then current-work handoff.
